# Secret Code & Cipher Toolkit in Python 🔐

A pure Python program that scrambles, unscrambles, and automatically cracks secret messages without any extra libraries.

#what it does
1. Caesar Cipher:*Hides messages by shifting letters forward in the alphabet (e.g., A becomes D).
2. Rail Fence Cipher: Scrambles messages by writing letters in a zig-zag pattern across rows.
3. Automatic Code Cracker: Cracks Caesar secret messages automatically without knowing the key, using a Python dictionary to count letter frequencies and spot the letter 'E'.
4. Automated Tests:Includes assertions to mathematically guarantee zero data loss.

run :
python ciphers.py
